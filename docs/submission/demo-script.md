# Six-minute demo runbook

0:00–0:40: Start with `bash scripts/demo.sh`. Sign in as investigator, open a deterministic hard scenario and explain synthetic provenance.

0:40–1:30: Load a case, start tracing, inspect transfer evidence and graph stop reasons. Run attribution and show the evidence supporting confidence.

1:30–2:20: Run the Dye Pack and inspect per-case coloured flows and exact base-unit amounts. Show impact and disclosure versus freeze recommendations.

2:20–3:10: Draft a request, switch to supervisor and demonstrate two-factor review. Dispatch through the mock integration and inspect the acknowledgement timeline.

3:10–4:10: Open Fence, approve the reported suspect proposal and replay recorded transfers. Inspect inbound Add/Tag as victim/Ignore decisions, dashed boundary, crossing alert and VASP pre-draft.

4:10–5:00: Load a scenario with dormant_days=45. Run trace and taint, open Dormancy and replay events. Show the quiet period, qualifying wake reasons, queued retrace from the awakened wallet and absence of automatic freeze.

5:00–6:00: Show System health, the benchmark report, held-out calibration metrics and explicit historical-public-dataset limitation. Download the evidence package and verify its seal and audit chain.

This is a recording runbook, not a completed demo video.
